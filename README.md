## Apple development

Generate a standalone Xcode workspace for iPhone, iPad, and native macOS:

```sh
npm ci
npm run apple:generate
npm run apple:open
```

See [Apple development](docs/apple-development.md) for prerequisites, signing, offline resources, and the existing Tauri command-line workflow.
